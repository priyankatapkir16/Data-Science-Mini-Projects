# Customer Segmentation using K-Means

## Overview

This project applies the K-Means clustering algorithm to group similar data points into clusters.

It demonstrates an unsupervised learning approach for customer segmentation.

## Features

- K-Means Clustering
- Cluster Visualization
- Data Segmentation

## Technologies Used

- Python
- Scikit-learn
- Matplotlib
- Pandas

## Learning Outcomes

- Unsupervised Learning
- Clustering
- Data Segmentation

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
