# OCR Text Recognition using EasyOCR

## Overview

This project extracts text from images using EasyOCR.

It demonstrates the application of Optical Character Recognition (OCR) for converting image-based text into machine-readable text.

## Features

- Image upload
- Text extraction
- OCR using EasyOCR
- Supports multiple image formats

## Technologies Used

- Python
- Flask
- EasyOCR
- OpenCV
- Pillow

## Learning Outcomes

- Computer Vision
- Optical Character Recognition
- Image Processing

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
