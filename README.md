# 📊 Data Science Mini Projects

## 📌 Overview

This repository contains eight hands-on Data Science mini projects completed during an 8-day Data Science Training Program. Each project focuses on a different Data Science or Machine Learning concept and demonstrates practical implementation using Python and its ecosystem.

The projects cover Natural Language Processing (NLP), Machine Learning, Statistical Analysis, Clustering, Recommendation Systems, and Optical Character Recognition (OCR).

---

## 🚀 Projects

| No. | Project | Description |
|-----|----------|-------------|
| 1 | Text Feature Extraction using Bag of Words & TF-IDF | Extracts numerical features from text using NLP techniques. |
| 2 | AI Sentiment Analysis Web App | Predicts sentiment (Positive/Negative) from user input text. |
| 3 | Logistic Regression Classifier | Implements Logistic Regression for binary classification tasks. |
| 4 | Decision Tree Classifier | Uses Decision Tree algorithm for supervised classification. |
| 5 | Customer Segmentation using K-Means | Groups similar customers using K-Means clustering. |
| 6 | Statistical Correlation Analyzer | Computes Pearson and Spearman correlation coefficients. |
| 7 | AI Habit Recommendation System | Recommends habits based on user preferences and data. |
| 8 | OCR Text Recognition using EasyOCR | Extracts text from images using EasyOCR. |
