# Statistical Correlation Analyzer

## Overview

This project analyzes relationships between variables using Pearson and Spearman correlation coefficients.

It helps understand how strongly variables are related.

## Features

- Pearson Correlation
- Spearman Correlation
- Statistical Analysis

## Technologies Used

- Python
- Pandas
- NumPy

## Learning Outcomes

- Correlation Analysis
- Statistical Methods
- Data Interpretation

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
