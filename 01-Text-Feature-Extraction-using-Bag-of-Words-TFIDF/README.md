# Text Feature Extraction using Bag of Words & TF-IDF

## Overview

This project demonstrates two popular Natural Language Processing (NLP) techniques used to convert textual data into numerical features for machine learning models.

The application performs text preprocessing and generates feature vectors using both Bag of Words and TF-IDF vectorization methods.

## Features

- Text preprocessing
- Bag of Words Vectorization
- TF-IDF Vectorization
- Feature extraction for NLP tasks

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas

## Learning Outcomes

- Understand text preprocessing
- Learn feature extraction techniques
- Prepare text data for machine learning

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
