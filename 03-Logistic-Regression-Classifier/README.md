# Logistic Regression Classifier

## Overview

This project demonstrates binary classification using the Logistic Regression algorithm.

It trains a machine learning model to classify input data and make predictions based on learned patterns.

## Features

- Logistic Regression model
- Model training
- Prediction
- Accuracy evaluation

## Technologies Used

- Python
- Scikit-learn
- NumPy
- Pandas

## Learning Outcomes

- Supervised Learning
- Classification
- Model Evaluation

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
