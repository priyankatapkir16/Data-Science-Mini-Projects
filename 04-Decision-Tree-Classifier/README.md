# Decision Tree Classifier

## Overview

This project implements the Decision Tree algorithm for supervised classification problems.

The model learns decision rules from data to classify unseen instances.

## Features

- Decision Tree Classification
- Training and Prediction
- Model Evaluation

## Technologies Used

- Python
- Scikit-learn
- Pandas

## Learning Outcomes

- Decision Trees
- Classification Algorithms
- Feature-based Learning

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
