# AI Sentiment Analysis Web App

## Overview

This project predicts the sentiment of user-entered text as Positive or Negative using Natural Language Processing and Machine Learning techniques.

## Features

- Text sentiment prediction
- User-friendly Flask interface
- NLP preprocessing
- Real-time predictions

## Technologies Used

- Python
- Flask
- Scikit-learn
- NLTK
- Pandas

## Learning Outcomes

- Sentiment analysis
- Text preprocessing
- Binary text classification

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
