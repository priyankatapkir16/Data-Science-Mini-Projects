# AI Habit Recommendation System

## Overview

This project recommends personalized habits based on user inputs and predefined recommendation logic.

The application demonstrates the fundamentals of recommendation systems.

## Features

- Habit recommendation
- User input processing
- Personalized suggestions

## Technologies Used

- Python
- Flask
- Pandas

## Learning Outcomes

- Recommendation Systems
- Data Processing
- Rule-Based Recommendations

## How to Run

```bash
pip install -r requirements.txt
python app.py
```
